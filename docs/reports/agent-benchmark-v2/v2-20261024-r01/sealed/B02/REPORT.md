## 实现
按 Unicode 标量一次拆分输入，使用带引号状态逐字符扫描；双双引号解码为一个双引号。引号内 CRLF/LF 直接保留；引号外 CRLF 作为单个行终止符处理。使用预分配字段字符缓冲、行字段缓冲与结果缓冲，下标写入，字段和行结束时截取有效部分；避免循环反复拼接字符串或 push 克隆数组。

空输入、单个空行、连续空行、尾随逗号与尾随行终止符分别处理。总扫描和有效内容复制量随输入长度增长，额外空间 O(n)。
