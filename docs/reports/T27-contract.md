# T27 冻结契约

## 28. T27 findIndex（2026-11-18 冻结）

### 28.1 调用与兼容
findIndex(predicate, array) -> int | nil。数组是最后一个参数，支持 [1, 2, 3] |> findIndex((x) => x == 2)，结果为 1。沿现语法解析直接和管道调用，内置名是普通标识符。

按原名字查找顺序处理调用。查到局部、捕获或当前模块全局的同名绑定时，调用其值。该值若不可调用，按现规则报 TypeError。只有不存在同名绑定的直接标识符调用才回落内置。字段和下标调用沿现规则。裸标识符取值时仍要求用户绑定，内置本身不是一等值。过去不存在同名绑定的 findIndex(...) 报 NameError，本节将这类调用定义为内置调用，并沿现内置规则先求实参。已有同名绑定的调用保持原派发。

### 28.2 快照、结果、错误与执行限额
沿现 HOF 左到右求实参，Hof::call 要求恰好两个参数。先按 filter 的 need_func 检查 predicate，再按 array_snapshot 检查数组并浅拷贝元素序列。即使数组为空也做两项类型检查。按快照由左至右逐个调用 predicate，唯一实参是该元素。每次调用走现 Invoke，按正常函数调用检查回调 arity，因此空数组不触发 arity 检查。快照固定本次访问顺序及索引，回调对原数组替换或增删元素不改变本次序列。嵌套容器保留共享引用。回调执行前释放原数组借用。

若回调返回 true，立即返回该元素从 0 开始的快照索引，类型为 int。false 继续。任何其它类型在内置调用位置报 TypeError::ConditionNotBool，沿 filter 的消息及位置契约。空数组与无匹配均返回 nil。首次匹配后没有更多回调。回调报错原样传播，保回调自身的源码与帧位置。步数、取消、截止、attempt 恢复和不可捕获的资源错误沿 filter 及同一求值会话的规则。快照和内置内部比较不计额外 LFZ 步。索引转为 i64 必须避免截断，超出表示范围时沿现 OverflowMsg::IntegerOutOfRange。

### 28.3 注册与同批内部优化
runtime 独占 builtins.rs。把 findIndex 按字母顺序加入 BUILTIN_NAMES、HOF_NAMES、HOF_TABLE，公开名单 76→77，高阶 7→8，普通与高阶表合计 72→73。lookup_hof/is_builtin/call_with 沿现注册语义，低阶 call 同其它 HOF 返回 NameError。严格式注册测试机械更新各计数与名单，保留对应关系及原行为断言。沿现 HofFn/Invoke API，无新错误类或 evaluator 特殊分支。

join 在同步校验和拼接期间可直接持数组不可变借用，由该借用取得字符串引用，无需克隆整个 Vec<Value>。从左至右仍先检查分隔符、数组及首个非法元素，使用同一类型错误、调用位置与结果。join 本身不调用用户代码。此变更不引入新的取消检查或计步点。原有 HOF 的快照依旧需要支持回调修改原数组。

### 28.4 验收
覆盖首项索引 0、中间匹配、空或无匹配 nil、管道、索引基于快照与嵌套共享、首次匹配后的回调副作用不会发生。核实非 callable/非数组/非 bool 错误、空数组回调 arity 边界、回调报错及执行限额原样传播。覆盖局部、捕获、全局同名和已绑定非函数。join 复用原输出及参数错误测试，至少覆盖空数组、单元素、多元素和首个非法元素。
