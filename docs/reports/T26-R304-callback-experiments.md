# T26 函数回调优化验收

本轮把候选实现、分段对照、功能回归及完整门槛评估纳入同一批，候选都独立从同一源码基线产生。A 与 B 的源码差异另存于 [结果目录](../../benchmarks/t26/results/)。

- **A** 仅在模块和 REPL 需要切换定义环境时保存并恢复 globals。普通调用省去原先的引用计数操作。完整链路从 103.297 变为 105.994 ms，正式对照 2/6 更快。两轮映射从 95.076 变为 92.150 ms。未达筛选条件，停止晋级。
- **B** 仅移除回调实参的临时 Vec。普通调用仍移动已拥有的实参向量，回调逐个克隆实参到参数槽，保有独立可写参数。模块与 REPL 的环境切换、数组快照、原生 ABI 和调用帧维护沿基线。完整链路从 99.389 变为 93.517 ms，正式对照 6/6 更快。两轮映射从 88.827 变为 84.008 ms，恒等映射从 31.078 变为 25.869 ms。达到筛选条件。

A 与 B 各通过 715 项 release 测试、37 项公开 REPL 和 27 项格式化检查。两次筛选各 70 条原始样本。空循环在两个窗口均有差距，跨窗口的绝对值不能直接相减。晋级只由预先约定的筛选条件决定，最终 R304 判定使用独立的原正式协议。

原型 A 二进制 SHA-256 `856eb2f7691f517778ddc604d3dd8c25f881144dc0b10ef434f53769439d74d7`。B 为 `7a14421320bc93d460d3be9abf48aa89b9c8091f7c6fc928ee11e860e52aa8ef`。全窗口固定使用 B，不在窗口中换版。

## 正式窗口与交付

独立复算核对 684 条记录，包括 532 正式样本和 152 预热。原 R304 的 **19/19** 全部通过，环境不确定与失败均为零。此前两项失败的 `string_map 8000` 与 `struct_small 64` 分别为 17.9885 ms 与 61.4684 ms，低于原 22.5214 ms 和 78.31068 ms。8,000 键结构体中位数 17.5651 ms，相比原基线 89.4598 ms 降低 80.3654%。九项 JSON/CLI 能力满足原预期，可测 JSON 解析 4k→8k 近似净时比 2.25335，低于 3.0。启动占比过高的组仅报告总时。见 [独立报告](T26-independent-verification.md)。

同期 T12 的 map 8,000 中位数为 17.3622 ms，候选仍约慢 3.6%。正式窗口确认候选过固定门槛，受控 A/B 提供该改动的局部收益证据。不同日期窗口的绝对值受当时环境影响，不能用 T24 到 T26 的差值估计补丁效果。

相同 B 另通过 17 套已有 CLI 与应用回归、JSONdesk 6 项、人类 REPL 指南 16 项、格式化指南 2 项、AI REPL 指南 8 项。交付时回读本地 dist SHA 与正式窗口一致。旧已交付二进制在项目 Temp 保存。候选精确 ZIP 含 27 个源码及 Cargo 文件与可执行文件，逐字节核对通过。R304 对指定 B 候选关闭，正式版本与标签未创建。历史失败、门槛和 Agent 旧成绩保留。

复算和重放命令见 [基准说明](../../benchmarks/t26/README.md)。
